# Dr. Paulo Vitor — Harmonização Orofacial

Site institucional do Dr. Paulo Vitor (CRO-RJ 53790), especialista em harmonização orofacial no Rio de Janeiro.

## Páginas
- `index.html` — versão em português (página principal)
- `en.html` — versão em inglês
- `images/` — fotos do site

O seletor de bandeiras (🇧🇷 / 🇺🇸) no cabeçalho alterna entre os idiomas.

## Como publicar
É um site estático (HTML/CSS/JS puro), sem build. Basta hospedar a pasta em qualquer serviço estático (GitHub Pages, Netlify, Vercel). O `index.html` é carregado automaticamente como página inicial.
